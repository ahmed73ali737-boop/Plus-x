# Eventna إيفنتنا Android — حزمة داخلية قيد المراجعة الأمنية

أُوقف تنزيل حزمة المعاينة بعد بلاغ مستخدم عن تحذير أمني على الهاتف. لا تتجاوز التحذير ولا تعطّل الحماية. استخدم نسخة الويب أثناء التحقيق. نجاح البناء أو التوقيع ليس حكمًا بخلو التطبيق من البرمجيات الضارة، ولا يرفع تصنيف جهة الحماية.

هذا تطبيق Android فعلي بواجهة بدء عربية أصلية وWebView لواجهة Eventna إيفنتنا الحالية، مع ماسح QR محلي. لا يُضمّن خادم FastAPI أو قاعدة PostgreSQL داخل الهاتف. الخصائص الإدارية وصلاحياتها تديرها المنصة نفسها؛ لا يوجد مصدر backend مكرر.

## الاستخدام

1. للفحص الداخلي فقط: APK المعاينة يدعم Android 8 أو أحدث. اسم الحزمة `com.pulsex.app.preview` مستقل عن أي حزمة إنتاج مستقبلية.
2. يستخدم البناء الداخلي الجديد `https://eventna.app` افتراضيًا. تظل إعدادات تغيير خادم المؤسسة متاحة عبر HTTPS وبموافقة المستخدم.
3. أدخل رمز الفعالية، ثم «فحص وحفظ». لا يتم الحفظ إلا إذا نجح فحص `/api/health` وعقده الأساسي.
4. افتح الفعاليات أو بطاقة الزائر أو الإدارة أو البوابة. تسجيل الدخول داخل المنصة؛ الأزرار لا تمنح صلاحية إدارية.
5. في البوابة، اربط جهازًا مصرحًا وجهّز السجل. زر `QR` أعلى الصفحة يفتح ماسح Android المحلي، ويعيد النص إلى نفس مسار التحقق والقيود. قراءة الرمز لا تُسجّل الدخول تلقائيًا.

## التصميم والخصائص

واجهة RTL ببطاقات كبيرة، تباين داكن/فيروزي، تنقل واضح، دعم تغيير اتجاه الشاشة دون إعادة إنشاء نموذج WebView، شريط تحميل، معالجة انقطاع الاتصال، وإعادة المحاولة. تبقى واجهات الجهات والعلامات والدعوات وRSVP والتصويت والاستبيان والإعلانات والتقارير حسب المصدر الحالي في main وصلاحيات المستخدم.

اختيار CSV/XLSX والصور عبر منتقي النظام؛ حفظ التقارير وQR عبر منتقي حفظ الملفات، بحد 8 MiB للتنزيل. لا حاجة لإذن تخزين شامل. قارئ QR يعتمد ZXing core 3.5.3 (Apache-2.0)، ويعمل محليًا دون خدمة Google أو اتصال لفك الرمز. يظل تأكيد الحركة والضوابط المعتمدة على الخادم خاضعًا لعقد البوابة، خصوصًا الدعوات ذات العدد/RSVP.

لا يتطلب التطبيق ميكروفونًا أو جهات اتصال أو موقعًا. يطلب الكاميرا عند استخدامها فقط. لا يتجاوز خطأ TLS؛ HTTP والوصول المباشر لملفات الجهاز غير مسموحين، ولا توجد JavaScript interface عامة. التنزيلات وطلب الكاميرا مقيدان بأصل الخادم. الروابط الخارجية تفتح بعد اختيار المستخدم في المتصفح.

## العمل دون اتصال

الصفحة الأصلية والإعدادات وفك QR لا تحتاج الشبكة. محتوى الفعالية والبطاقات وطابور العمليات تتبع IndexedDB وService Worker الموجودين في Eventna إيفنتنا، ويلزم تجهيزها أثناء الاتصال. لا يُدّعى عمل كل العمليات الإدارية أو الدعوات المُدارة دون خادم، ولا اختبار خمسة أيام على جهاز فعلي.

عند تغيير الخادم يُطلب تأكيد حذف بيانات WebView والجلسة، مع تنبيه لمزامنة العمليات أولًا. لا تحذف التطبيق أو بياناته مع وجود عمليات لم تُزامن.

## البناء

JDK 17، Android platform 35، Build Tools 35.0.0. افتح مجلد android في Android Studio أو استخدم Gradle 8.9 وAGP 8.7.3:

```bash
cd android
./gradlew :app:assembleDebug :app:lintDebug
```

مسار ثانٍ محدود باستخدام أدوات SDK الرسمية، دون حل تبعيات Gradle:

```bash
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk
python3 tools/build_android_apk.py
```

الأداة تثبت مصدر SHA، وتتحقق من SHA256 لـZXing، وتنفذ aapt2/javac/d8/zipalign/apksigner، ثم تنتج `android/app/build/manual/Eventna-Android-preview.apk` و`BUILD_EVIDENCE.json`. إذا كانت الشجرة معدلة، يُذكر ذلك صراحة ولا ينسب البناء إلى commit نظيف.

سير Android APK يرفع حزمة اختبار مرتبطة بـSHA. مفتاح التوقيع تجريبي محلي؛ لا يُحفظ في Git ولا يصلح للنشر التجاري. احفظ وادِر مفتاح إنتاج منفصلًا قبل اعتماد الإصدار والتحديثات. اختلاف مفتاح المعاينة بين بيئتين قد يمنع التحديث فوق حزمة قديمة؛ زامن البيانات قبل إزالة أي نسخة.

## حدود القبول

توقيع APK وبناؤه وفك QR بالصور لا تثبت كاميرا هاتف فعلي أو دورة المستخدم على خادم منشور. بوابات الجهاز الفعلي، الكاميرا، رفع/تنزيل الملفات، عودة التطبيق من الخلفية، مزامنة جهازين، واختبارات الإنتاج مستقلة، وتُسجّل نتائجها دون تحويل NOT_RUN إلى PASS.

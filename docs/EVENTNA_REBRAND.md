The product is now named **Eventna إيفنتنا**, served at **https://eventna.app**.

icons and Android preview branding use the new name. The shorter platform
title replaces only the previous default title, preserving content and history.

package IDs and protocol identifiers remain stable. The former download URL

separate from this branding and deployment change.

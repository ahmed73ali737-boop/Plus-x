# إصلاح B-02 — سجل رفض الدخول والصلاحيات

الأساس: main 83eba6e816b9a895eb025d621c98d5dbe89cd0b0؛ المرجع #27، تمت قراءة القضية وتعليقاتها ونشر تنسيق بدء العمل في التعليق 6443891016. نطاق B-01 والشهادات واسترداد الحسابات الأوسع خارج هذا الإصلاح.

## التنفيذ

يرفع login والحراس القائمة استثناء HTTP متخصصًا يحمل فقط نوع الحدث وسببًا ثابتًا وهوية فاعل موثوقة ومعرف نطاق تحقق منه الخادم عند توفرهما. معالج الاستثناء في التطبيق يكتب عبر خدمة التدقيق بمعاملة مستقلة بعد خروج معاملة المسار وتراجعها؛ لا تكتب الحراس داخل معاملة محكوم عليها بالتراجع. تبقى استجابات الرفض ورموزها دون تغيير. لا تمنح صلاحيات جديدة، ولا تغير صلاحيات قراءة السجل.

فشل الدخول لا يثبت هوية المستخدم: الفاعل والنطاق فارغان حتى عند تطابق معرف حساب. لا تحفظ كلمة المرور أو الرموز أو معرف الدخول أو رؤوس الطلب أو عنوان IP. رفض النطاق يستخدم المستخدم الموثق والنطاق المحلول من DB، دون تفاصيل الطلب.

كل محاولة HTTP مستقلة حدث مستقل، حتى عند تكرارها. تكرار معالجة الاستثناء نفسه لا يولد حدثًا ثانيًا. ذاكرة منع التكرار محدودة بـ600 مفتاح لمدة 60 ثانية، وسقف عام 600 محاولة حفظ/دقيقة/عامل يشمل محاولات التخزين الفاشلة. لا تُوثق IDs قادمة من العميل. فوق السقف تُسقط أحداث التدقيق فقط ويستمر الرفض. العدادان failures وsuppressed في app.state.denial_audit قابلان للفحص التشغيلي. رسالة فشل الحفظ ثابتة ولا تطبع استثناءات SQL. تحديد المعدل محلي للعامل، وليس حصة موزعة أو ضمان تسليم عند تعطل قاعدة البيانات؛ مع N عمال يصبح الحد 600N. لا يوجد outbox يعيد المحاولة أو ادعاء عدم فقد الأحداث عند عطل التخزين.

## التحقق

- SQLite: 213 اختبارًا ناجحًا في `tests/test_denial_audit.py` و`tests/test_functional_screen_permissions.py`، بما فيها الاختبار الأصلي دون تعديل أو إسكات. السجل في evidence/b02/sqlite-targeted.txt.
- التغطية الجديدة: كتابة فعلية قبل rollback ثم ثبوت اختفائها وبقاء التدقيق، تعطل خدمة الحفظ مع استمرار 401 وعدم تسريب الاستثناء، تكرار HTTP، منع تكرار نفس الاستثناء، حد الإغراق وانقضاء النافذة، قراءة أحداث الدخول الفاشل بواسطة المنصة فقط. الحزمة القائمة تختبر 403 وعزل قراءة سجل الفعاليات.
- PostgreSQL: غير منفذ؛ لا يتوفر خادم أو عميل PostgreSQL أو Docker في البيئة، ولم تُقدم قاعدة اختبار. لا يُستنتج نجاحه من SQLite.
- البيئة: Python 3.12، FastAPI 0.162.0، SQLAlchemy 2.1.6، pytest 9.1.1، httpx 0.28.1؛ هذه ليست نسخ جميع أقفال requirements، لذا إعادة الاختبار بالاعتماديات المثبتة بالمشروع لازمة لقبول الإصدار.
- لا قبول إنتاج أو UAT أو متصفح أو حمل متعدد العمال أو GitHub CI مثبت بهذا التغيير؛ نجاح الحزمة الجزئية ليس قبول النظام كله. لا تُحذف مشكلة B-01 أو تُسكت اختباراتها.

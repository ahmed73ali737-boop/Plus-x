# خدمة الشهادات الذاتية

تضيف هذه النسخة مكتبة خاصة بالحساب وروابط طلب ثابتة النسخة، وتوليد PNG أصلي محفوظ، واستلامًا خاصًا وتحققًا عامًا محدود البيانات، وسجلًا وتصدير CSV/XLSX. يبقى سجل شهادات الفعالية السابق منفصلًا.

## العقود المعتمدة

- إدارة المكتبة مستقلة عن وجود فعالية، وتبقى ملكية الحساب شرطًا حتى لدور المنصة. إنشاء الرابط يحتاج فعالية مخولة وعلاقة حية.
- لا OTP أو إثبات حضور أو حساب إلزامي للمشارك. التفرد للمتصفح/الرابط؛ الهاتف ليس مفتاح منح فريدًا.
- تعليق صاحب الرابط أو سحب علاقته يمنع الجديد ويحفظ السابق والمقبول.
- خلفية PNG/JPEG/PDF حتى 3,000,000 بايت، ختم PNG أقل من 1,000,000، 18MP. PDF صفحة واحدة غير مشفرة؛ حد 2× للخلفية المحولة قبل الطبقات، مع رفض تعارض الجودة والحجم.
- بطاقة RTS الأصلية بعرض 14%، محفوظة ضمن بكسلات الصورة. QR الطلب مستقل، ولا يطبع على الشهادة.
- الاسم الأصلي والمطبوع منفصلان؛ تصغير أولًا ثم حذف قبل الأخيرة دون الأولى/الأخيرة عند الحاجة.
- تذكر المتصفح 365 يومًا؛ لا انتهاء لصادر محفوظ أو قدرة استلامه بسبب انتهاء التذكر.
- التصدير سبعة أعمدة وكل حالات الحساب. عضوية الصفوف والقيم والحالات ثابتة عند قبول تأكيد الطلب، ولا تتبدل عند claim أو retry. البحث لا يحد التصدير.
- ملفات التصدير ولقطاتها مؤقتة سبعة أيام؛ لا حذف لطلبات المشاركين أو صور الشهادات بهذه السياسة.

## التشغيل

التهيئة في .env.example وCompose. العلمان PX_SELF_CERTIFICATES_ADMIN وPX_SELF_CERTIFICATES_ACCEPT_NEW افتراضيًا false. نطاقا pilot الاختياريان للحسابات والفعاليات لا يغيران حقوق استلام السابق. العمال الافتراضيون ستة، ومنتخب واحد يدير مجموعتهم عبر عمليات ASGI، وستة أقفال رسم عامة بالمخزن المشترك.

الرسم ومعالجة الرفع يتطلبان Linux مع Landlock ABI3+ وlibseccomp. لا يوجد سقوط إلى فك غير معزول على Windows أو مضيف لا يدعم الحماية. يمكن تشغيل وظائف النظام الأخرى، وتعيد جاهزية الشهادات سبب عدم توفر القبول/الرسم عند تفعيلها على بيئة غير مناسبة. ملفات runtime/venv المقروءة مسموحة للعزل دون منح جذر المشروع أو المخزن الخاص أو المفاتيح.

تهيئة ملفات runtime وQA مثبتة بالبصمات وتشمل fonttools وpypdfium2. ملفات catalog المعنونة بالـSHA مستثناة صراحة من تحويل نهاية السطر في Git، لأن البصمة لعينة البايتات الأصلية.

## البيانات والترقية

الترحيلات 016–019 محفوظة، و020 تضيف اللقطة، و021 سلسلة المالك، و022 هوية إنشاء النموذج. preflight يتوقف عند بيانات مخالفة دون تغيير ملكية أو حذف سجل. الحذف الحقيقي للنموذج يفصل مرجع الأصل فقط ويحفظ النسخ والروابط والصادر.

لا يشغّل عامل تصدير قديم أمام مهام V3. المهام القديمة بلا لقطة تستلزم تصديرًا جديدًا؛ الملفات القديمة المكتملة تحتفظ بمدة إتاحتها. الرجوع الآمن يوقف الجديد مع إبقاء قارئ وعامل متوافقين، دون down-migration أو حذف الصادر.

المفاتيح خارج الصورة، وإصداراتها القديمة محفوظة عند التدوير. أدوات النسخ والاستعادة والتدوير في tools؛ النسخ يتطلب إيقاف جميع الكتّاب، والاستعادة إلى قاعدة ومجلد جديدين. ZIP النسخ خاص وغير مشفر بذاته؛ يحتاج تخزينًا موثوقًا ومحميًا لدى المشغل.

هدف RPO يوم وRTO ثماني ساعات؛ الجدولة والحماية والقياس على حجم الإنتاج إجراءات قبول مستقلة.

## الفحص

~~~sh
python -m pip install --require-hashes --only-binary=:all: -r requirements/locks/qa-postgres.txt
python -m pytest -q tests/test_self_certificate*.py tests/test_certificates.py
~~~

تستخدم اختبارات البيانات قواعد مصطنعة وتحتاج لاختبارات PostgreSQL الاختيارية PX_ALLOW_CERTIFICATE_TEST_DATABASES=YES وPX_CERTIFICATE_TEST_ADMIN_URL لقاعدة اختبار إدارية مستقلة. لا تستعمل قاعدة التطبيق الحية. مخطط ما قبل V3 محفوظ كـfixture متتبع، ولا تحتاج اختبارات الترقية لأرشيف محلي خاص.

PX_CERTIFICATE_TEST_EVIDENCE_DIR اختياري لملفات الفحص؛ الافتراضي مجلد الاختبار المؤقت. رحلة المتصفح تحتاج PX_SELF_CERTIFICATE_BROWSER_ACCEPTANCE=YES وChromium مثبتًا. ملف workflow الشهادات يلزم العزل الفعلي، ويشغّل SQLite وPostgreSQL والمتصفح وحمل smoke من 100 طلب. لا يقدم هذا قياس GitHub ادعاء قبول 1000 طلب على موارد محلية مختلفة.

## أدلة ما قبل نشر PR وحدودها

سجل التطوير المحلي تضمن 200 عقد آلي فريد ناجح و21 تحققًا في رحلة Chromium، وثلاث جولات 1000 طلب/20 رابطًا/6 عمال في 73.899/83.576/89.585 ثانية، وتجربة 1020 في 99.068 ثانية، دون فقد أو تكرار. عينة الأداء 1200×800 و4CPU/4GiB وPostgreSQL بموارد مستقلة محددة. نجح فحص ست خلفيات وستة أختام 18MP بذروة cgroup نحو 2.40GB.

هذه نتائج لنسخة ما قبل تكييف PR. تغييرات PR تضيف قابلية نقل CI والعزل إلى مسارات مكتبات غير /usr؛ قبول الرأس المرفوع يعتمد نتائج الفحوص الجديدة وCI على ذلك الرأس، ولا تنقل الأرقام تلقائيًا إليه.

التوثيق التفصيلي والأرشيف المحلي محفوظان في مجلد التدقيق المستثنى من Git. هذا الملخص قابل للنشر ولا يحمل بيانات اعتماد أو سجلات مشاركين حقيقية.

## بوابات القبول الباقية

# PulseX Pilot 02 — تقرير التحقق الفعلي

**التاريخ: 28 سبتمبر 2026.** النتيجة: خادم تجريبي وواجهات ومكونات مثبتة جزئيًا، مع بقاء بوابات قبول مهمة غير منفذة. ليس اعتماد نشر عام أو أمن أو تجربة خمسة أيام.

## النتائج

| الفحص | النتيجة | الدليل وحدوده |
|---|---|---|
| Python compileall + JavaScript node --check | نجح | صحة بناء لغوي، لا تثبت سلوك المستخدم |
| اختبارات الخادم والمنطق والإدخال والصلاحيات | 75 نجح | `qa/unit-integration.txt` وXML؛ SQLite وFastAPI TestClient |
| اتصال HTTP محلي فعلي | 7 فحوص نجحت | `qa/http-smoke.json`؛ Python clients ↔ Uvicorn ↔ SQLite |
| 1000 مشاركة اصطناعية متميزة | 1000 سجل محفوظ | أربع عمليات عميل متوازية، دفعات 50؛ ليست 1000 مستخدم متزامن |
| إعادة إرسال 50 جسمًا بالمعرف نفسه | بلا صفوف إضافية | قبول idempotency في الخادم التجريبي فقط |
| متصفح متصل بالخادم End-to-End | محجوب ولم يُعتمد | `qa/browser-smoke.json`: ERR_BLOCKED_BY_ADMINISTRATOR عند أول انتقال |
| مكونات DOM في Chromium ببيانات قراءة اصطناعية | 9 فحوص نجحت | `qa/browser-components.json`؛ لا اتصال API فعلي من المتصفح ولا إثبات IndexedDB |
| PostgreSQL أصلي وpsycopg | لم ينفذ | ملفات ربط وDDL وقالب نشر فقط؛ لا psql أو PostgreSQL server في بيئة الإعداد |
| Docker / Caddy / HTTPS على مضيف فعلي | لم ينفذ | لم تتوفر بيئة نشر مع حسابات ونطاق مصرح |
| Service Worker وقطع فعلي على تابين | لم ينفذ | كود مرفق وبروتوكول قبول، لا نتيجة ميدانية |
| استمرار خمسة أيام / استعادة ميدانية / اختبار اختراق | لم ينفذ | لا شهادة أمان أو أداء أو زمن استمرار |

## تفاصيل ما تغطيه الاختبارات الـ75

إنشاء وعزل المساحات؛ هوية وجلسة وصلاحية وCSRF؛ إدخال ونشر مقابل مسودة؛ منع تعارض الحفظ والاستيراد؛ أنواع الأسئلة الـ13؛ التحقق من خيارات ونصوص وقيم؛ جميع قوالب CSV للمواد؛ XLSX سليم/صيغ مرفوضة؛ اختيارات الترحيب والموافقات؛ مسارات المستلم/المكرر/المرفوض؛ تصويت مكرر وتصويت مغلق؛ تقييم جهة من صفحة الحدث؛ إحصائيات دون نشر النصوص الشخصية؛ ضبط إنشاء الحسابات؛ QR؛ منع رفع SVG غير موثوق؛ تغيير كلمة المرور وإلغاء الجلسات.

الفحوص مستقلة؛ لا تعني تغطية كل احتمالات الخطأ أو كامل الـSRS. التبعيات المختارة هي المتاحة أثناء التنفيذ؛ لا ادعاء أنها خالية من الثغرات. يلزم فحص تبعيات وصور نشر ومراجعة أمنية في البيئة المقصودة.

## صور الواجهة

`platform-desktop.png`، `agency-desktop.png`، `agency-mobile.png`، `admin-overview.png`، `manual-question-editor.png`، `import-component.png` التقطت من **مكونات DOM الفعلية مع fixtures للقراءة**؛ ليست صورًا مولدة تخيلية، لكنها ليست دليل تشغيل متصفح متصل أو موقع منشور. بياناتها وأسماؤها توضيحية. `template-preview.png` مراجعة مرئية لقالب الإدخال.

لم يتم تعديل سياسة المتصفح لتجاوز الحظر. اختبار المتصفح الفعلي متاح في `tests/browser_smoke.py` لإعادة تشغيله في بيئة اختبار مصرح بها؛ فشله أو نجاحه هناك يُسجل مستقلًا. لا تُستبدل حالة «محجوب» بـ«نجح» بسبب نجاح فحوص المكونات.

## مصدر مستقل لا ترقية مدمجة

الأصل Build01 محفوظ كما ورد في `reference/`. هذه الدفعة Python/FastAPI/SQLAlchemy مستقلة؛ اختبارات Node/Fastify/React السابقة لم تُنفذ هنا ولا يرثها هذا التسليم. SQLite هو الخلفية التي نُفذت عليها الاختبارات المرفقة؛ قبول PostgreSQL لا يستنتج من ترجمة DDL أو استدعاء dialect.

## بوابات السماح بالتجربة

قبل بيانات حقيقية: تشغيل PostgreSQL أو اعتماد خلفية تجريبية بديلة بصراحة، واستعادة نسخة احتياطية، وصلاحيات متصفح فعلية، ومراجعة سياسة مشاركة بيانات المنظم والجهات، وHTTPS. وقبل إعلان Offline: نجاح محضر التابّين. وقبل تعميم 70 جهة: قياس تزامن واقعي واختبار حمل مناسب، لا تحويل 1000 مشاركة اصطناعية إلى ادعاء قدرة لـ1000 زائر في لحظة واحدة.

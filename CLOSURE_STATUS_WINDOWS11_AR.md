# حالة الإغلاق — Windows 11

## مثبت ومختبر محليًا

- Platform / Event / Organization / Participation hierarchy.
- Organizer creation from Platform.
- Participant organization creation from Organizer.
- Display-only organization without account.
- Organization people without account.
- Optional account creation later for a person.
- Temporary password + forced password change before Admin use.
- Membership and participation lifecycle.
- Public Visitor without login.
- Survey, voting, rating, notes, contact remain public interaction flows according to published page policy.
- QR source tracking.
- Kiosk visitor reset model.
- Server-side offline/idempotency receipts.
- Admin, questions/surveys, themes, RTS/Easy templates, import/export and prior functional modules from Windows 10.

- Native IndexedDB/Service Worker.
- physical two-device outage/recovery.
- 5-day offline soak.
- Windows native E2E.
- PostgreSQL/RLS native.
- production HTTPS/domain.
- production load/security/field UAT.

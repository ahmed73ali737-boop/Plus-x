PULSEX · WINDOWS 04

المنصة والفعاليات والمؤسسات في مسار واحد.

موقع عام للاشتراك، فعاليات جارية وقادمة ومنتهية، صفحات جهات، قوالب وهوية، أسئلة وتصويت وحقائق وخدمات وتقييمات وملاحظات وتحليلات.

التشغيل

شغّل Start-Windows.cmd واترك النافذة مفتوحة. الحسابات الأولية: Open-Accounts.cmd.

أول تشغيل يحتاج Python 3.11–3.13 وإنترنت لتنزيل المتطلبات.

الموقع العام

http://127.0.0.1:4310/

هنا طلب الاشتراك، وعرض ما يجري وما سيجري وما انتهى، ثم الدخول إلى كل فعالية.

http://127.0.0.1:4310/admin

المؤسسات والمشاركات، الهوية والقوالب، الأسئلة، التصويت، الحقائق، الخدمات، الإعلانات، النتائج والسجل.

ما الجديد

  • المؤسسة دائمة ومشاركتها في كل فعالية مؤقتة.
  • 8 قوالب مظهرية و5 نماذج عرض للأقسام.
  • 20 نوع سؤال، 5 نماذج تصويت، 8 أشكال حقائق، و8 أنواع خدمة/منتج.
  • معايير تقييم مخصصة وملاحظات مكتوبة تظهر للإدارة.
  • عضويات المؤسسة وحالاتها وفترة صلاحية المشاركة وسجل تدقيق.
